# Smoke test log

Write the 10 queries BEFORE indexing. Score after. One table per run. Hit = the shot you meant is
in the top 5. Target 8/10.

## How to run

1. Pick a footage set (~5 h for the real smoke; `fixtures/` for the clean-machine check).
2. Fill the query column in a fresh copy of the template below **before** you add the folder.
3. Library → Add Folder…, note the wall-clock start. Keep working in another app while it indexes
   and answer "laptop usable" honestly (fan, stutter, beachballs).
4. When every video is Done, run the ten queries. Score, then write down every annoyance —
   the 12c hard stop and Task 13 both read this file.

## Default queries

Use these when the footage is generic; replace any that cannot apply to the set. They cover the
three things CLIP is good at (objects, scenes, actions) plus two transcript-driven queries.

1. wide shot of a building exterior
2. close-up of a person's face talking to camera
3. two people shaking hands
4. someone walking away from the camera down a street
5. car driving on a road
6. text or a sign in the frame
7. crowd of people
8. drone shot from above
9. someone says "thank you" *(transcript)*
10. someone says the product or company name *(transcript)*
