# Crush

Search your footage in plain English. Splits video into shots, describes each with CLIP and Whisper, and finds the one you meant — entirely on your Mac. No server, no account, no upload.

**Status:** pre-alpha. Apple acceleration feasibility is proven; the storage layer is complete and
the reference answer-key kit is in progress. See `TASKS.md`.
